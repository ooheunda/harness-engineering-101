Harness Engineering 101 (원문은 영어, 저작: Isuru Wijesiri)을 3주간 공부하며 쌓는 노트.

## 학습 방법

번역하지 않고 영어 원문을 읽는다. 책을 덮고 기억에서 꺼내 쓰는 것(인출 연습)이 다시 읽는 것보다 오래 남기 때문에, 장마다 아래 순서로 돈다. 하루 1시간, 장당 1~1.5시간.

1. 예상: README 표의 "패치하는 실패"만 보고, 이 장이 뭘 말할지 추측해 적는다 (틀려도 됨).
2. 읽기와 실험 (약 40분): 장을 읽고, 해당 코드를 `실험/`에 복사해 돌려 본다.
3. 초안 (약 20분): 책을 덮고 `초안/`에 6칸을 채운다. 모르면 비우거나 "막힌 것"에 적는다.
4. 피드백: Claude에게 초안을 보여 준다. 맞게 이해한 것, 틀리거나 흐린 것(원문 근거), 빠진 핵심, 되묻는 질문을 받는다. Claude가 노트를 대신 고쳐 쓰지는 않는다.
5. 최종: 피드백을 반영해 `최종/`에 내 말로 다시 쓴다. 틀렸던 부분은 "내가 틀렸거나 놓쳤던 것"에 남기고, 받은 피드백 요약은 "선생님 보정 메모"에 붙인다.

나중에 다시 볼 때와 발표 준비는 `최종/`만 본다. Claude Code에서의 동작 매핑은 시간이 남을 때만 하고, "확인한 것"과 "추측"을 구분해 쓴다.

## 규칙

- 원본 파일(`src/`, 루트 `README.md` 등)은 수정하지 않는다. 노트와 실험은 이 폴더 안에서만 한다.
- 노트는 번역이 아니라 본인 말 요약이다. 원문 인용은 짧게만 한다.
- 코드는 `src/harness/`를 고치지 않고 `실험/`에 복사해서 고친다.
- 회사 앱/고객 관련 내용은 노트에 쓰지 않는다 (공개 포크일 수 있음).
- 파일명: 초안 `초안/YYYY-MM-DD_chNN-제목.md`, 최종 `최종/chNN-제목.md`. 틀은 [템플릿_초안.md](템플릿_초안.md), [템플릿_최종.md](템플릿_최종.md).
- 하루 1시간. 장당 1~1.5시간. 주말은 밀린 것과 Claude 매핑용 버퍼.
